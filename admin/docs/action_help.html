System Management

The System Management interface provides control over the internal services and hardware power states of your device.

Service Maintenance

This function restarts the background services that power your dashboard and portal.

Requirement: System Refresh

To ensure system changes are applied, a service restart is required for the following reasons:

  • Cache Clearing: The system stores data in temporary memory for efficiency. A restart clears this data, ensuring new updates are loaded correctly.
  • Subsystem Sync: Restores the internal connection between the web interface and the core logic modules.
  • UI Synchronization: After the restart, you must reload your browser to synchronize with the updated interface and settings.

Hardware Power Control

Provides standard instructions for system power cycles:

  • Reboot: Performs a safe hardware restart.
  • Power Off: Safely shuts down the system hardware.

Developer Key Management

This interface allows you to manage trust for external software contributors. By importing an Orange WiFi Key (.owk), you enable a specific developer to provide updates for your system.

Security Architecture: Sandboxed Updates

Trust is managed through a multi-tier hierarchy to protect system integrity:

  • Restricted Scope: Third-party updates are confined to the orange-wifi software directory. They cannot modify system files or configurations.
  • Information Audit: Every package includes developer identity and contact information. Review these details carefully before providing access.
  • Revocable Trust: You can remove a developer's access at any time by deleting their entry from the list, blocking all future updates from that source.

System Updates

The System Updates interface allows you to deploy new features, bug fixes, and improvements using Orange WiFi Packages (.owp).

About System Update:

The system processes updates through two primary paths based on the package source:

  • Official Updates: Primary updates provided directly by the software distributor. These packages are validated for compatibility to ensure system authenticity.
  • Third-Party Updates: Software modules provided by enabled external developers. These packages are audited and confined to the orange-wifi software boundaries to protect system stability.
  • Installation Telemetry: All updates provide a real-time console log. Monitor this terminal to verify the successful staging and synchronization of your files.

Note: Do not disconnect power or interrupt the network during an active update sequence to prevent system state errors.
