System Logs Help

Kernel Log

Displays the real-time kernel ring buffer (dmesg). This is essential for hardware troubleshooting, identifying USB device connections, and monitoring kernel-level security events.

CYBERSECURITY TIPS

Monitor your Kernel Logs for high-priority security warnings. A specific indicator of a network-layer attack is the following record:

[ATTACK: SYN Flood Warning]
[ 31.026672] TCP: request_sock_TCP: Possible SYN flooding on port 0.0.0.0:80. Sending cookies.

Another critical indicator is a high-frequency sequence of ICMP block logs. Note: These logs are only generated when ICMP Flood Protection is ACTIVE. If the protection is disabled, you must instead monitor for an abnormal rise in TX and RX traffic on the Overview dashboard.

[ATTACK: ICMP Flood Blocked]
[ 855.733833] [ORANGE-WIFI-ICMP-BLOCK] IN=eth0 OUT= MAC=02:81:88:21:5b:c9:00:21:9b:da:4f:63:08:00 SRC=192.168.100.16 DST=192.168.100.44 LEN=28 ... PROTO=ICMP TYPE=8 CODE=0
Log Breakdown:
  • IN=eth0: The interface where the attack was intercepted.
  • MAC: The combined Destination and Source hardware addresses.
  • SRC: The IP address of the attacker initiating the flood.
  • DST: Your Orange Pi's local IP address.
  • PROTO=ICMP: Confirms the attack is using the Ping protocol.
  • TYPE=8: Indicates an "Echo Request," the standard Ping probe.

WARNING: If these logs appear frequently, enable DoS Defense immediately to prevent network saturation.

Authentication Log

Provides a view of the secure `/var/log/auth.log` file. Use this to monitor:

  • Sudo attempts: See every command run with root privileges.
  • System Logins: Monitor console and background service authentications.

Task Viewer

A real-time snapshot of running processes, CPU load, and memory usage. It acts as a web-based task manager for your Orange Pi, allowing you to see which services are consuming resources.

The Task Viewer automatically refreshes every 5 seconds.
