Portal Design Help

The Portal Design suite allows you to customize the visual appearance of your captive portal without touching any code.

Custom Backgrounds
  • Uploading: You can drag and drop any image into the upload zone or click to select a file.
  • Compatibility: Only JPEG and PNG formats are accepted. The system performs integrity checks to ensure the file is a valid image.
  • Live Preview: Once a file is selected, a preview will appear on the right side. The changes are not permanent until you click "Apply Background".
  • Automatic Sync: Once applied, the background is instantly synchronized to all portal pages (Home, Rates, Transactions, etc.).
Typography & Fonts
  • Font List: The system automatically detects all .ttf font files located in your /fonts directory.
  • Multilingual Support: You can verify if a font supports international characters (like Japanese or Arabic) by checking the preview box. If the characters appear as boxes, that font does not support that language.
  • System Default: You can always revert back to the high-performance Standard System Font by selecting it from the dropdown and clicking apply.
Best Practices
  • Use high-resolution images (at least 1920x1080) for the best background quality on PC and Mobile.
  • Ensure your background image doesn't clash with white text. The "Glassmorphism" effect helps readability, but very bright images might require choosing a bolder font.
