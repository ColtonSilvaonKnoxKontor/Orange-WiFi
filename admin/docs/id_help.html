Orange Star ID Help

What is it?

The Orange Star ID is a unique, hardware-locked security identifier. It is cryptographically derived from the immutable characteristics of your specific device, creating a permanent bond between the SilvaSystems software and your physical hardware.

Why is it critical?

This ID serves as your Master Recovery Key and the foundation of the system's trust model:

  • It ensures the system cannot be cloned or run on unauthorized hardware.
  • It acts as a mandatory second factor for sensitive operations, such as password recovery.
  • It prevents "Database Hijacking" – even if an attacker steals your configuration, they cannot use it on another device.

Managing Your ID

In the Licensing & IDs menu, you can view your unique ID. It is your responsibility to secure this ID immediately.

  • Burning the ID: Once you have secured a copy, use the "Burn ID" feature. This permanently removes the ID from the dashboard interface.
  • Masking: After burning, the ID is masked (e.g., 8f3a...****) and can never be retrieved through the user interface again.

Identity Rotation & Emergency Recovery

If your Orange Star ID is compromised, stolen, or exposed to an unauthorized party, you must rotate the system's internal security seeds to invalidate the old ID and generate a new one.

Emergency Rotation Protocol

To secure the system after an ID leak, follow these steps to perform a hardware-level reset:

  1. Connect a physical monitor via HDMI and a keyboard directly to the Orange Pi.
  2. At the system login prompt, enter the dedicated recovery credentials: User: ussr | Password: ussr.
  3. The system will automatically initiate the Hardware Integrity Verification utility.

Note: This process requires physical access to the console. The utility will perform a security audit and automatically regenerate the system's internal keys. Once the process is complete, your New Orange Star ID will be displayed on the screen.

You must use this new ID to reset your administrative password via the "Forgot Password" mechanism immediately after the rotation is complete.

Fatal Warning

If you lose your Orange Star ID after burning it, and you also lose your Admin Password, the system becomes unrecoverable via the web interface. This is a deliberate security measure to ensure that only the physical owner can maintain control.
