Identity Rotation Help

Emergency Security Protocol

If your system's hardware identification has been leaked, stolen, or accessed by an unauthorized party, you must perform a Hardware Identity Rotation. This process regenerates the system's internal security signatures, rendering the old identity useless.

Rotation Procedure

To safely rotate the system identity, follow these steps:

  1. Connect a physical monitor via HDMI and a keyboard directly to the hardware.
  2. At the system login prompt, enter the dedicated recovery credentials: User: ussr | Password: ussr.
  3. The system will automatically initiate the Hardware Integrity Verification process.

Security Note: This utility requires physical presence at the console. It will perform a comprehensive security audit and automatically rotate the internal cryptographic seeds. Once the process is complete, your New Orange Star ID will be displayed on the screen.

Warning: You must use the new ID to reset your administrative password via the "Forgot Password" mechanism immediately after the rotation is finished.

Prerequisites

  • Direct physical access to the device.
  • HDMI-compatible display.
  • USB Keyboard.
