Networking Help

DoS Defense

Manage real-time mitigations against common Denial of Service (DoS) attack vectors to ensure the stability of the Orange WiFi distribution.

  • SYN Flood Protection: Mitigates TCP handshake exhaustion by enabling kernel-level SYN Cookies and enforcing aggressive firewall-level connection limits.
  • ICMP Flood Protection: Rate-limits incoming Ping requests (1 per second) to prevent network saturation and CPU overhead from ICMP-based attacks.
  • HTTP Flood Protection: A hybrid Layer 4 and Layer 7 defense that throttles rapid-fire HTTP requests and breaks persistent connections based on your defined threshold.
DoS DETECTION TIPS

Monitor these system areas to identify and verify the interception of active attacks:

  • Kernel Log: Check for [ORANGE-WIFI-ICMP-BLOCK] or Possible SYN flooding messages indicating hardware-level mitigation.
  • Network Throughput: Observe the Overview dashboard for sudden, unexplained spikes in packet frequency without corresponding traffic.
  • Web Access Log: High-frequency repeated requests from a single IP (e.g., thousands of hits per second) indicate a Layer 7 HTTP flood.

Network Information

Displays the detailed configuration of all physical and virtual network interfaces on the Orange Pi.

  • eth0: The WAN/Internet interface (usually connected to your router).
  • eth1: The LAN/Client interface (where your WiFi AP is connected).
  • lo: Local loopback interface.

Web Access Log

Displays every HTTP request processed by the system. Use this to audit client portal visits and identify suspicious web activity.

CYBERSECURITY TIPS

Audit the Access Log for these signatures of automated hacking tools (Kali/Parrot OS, Termux, NetHunter, or Exploit Software):

  • Network Scanning & Discovery (nmap, ffuf): Attackers use Nmap to probe services and tools like ffuf to scan for hidden paths. Look for "Nmap Scripting Engine" or empty User-Agents ("-").
    [RECON: Nmap Scripting Engine]
    10.0.0.11 - [07/Mar/2026] "GET /nmaplowercheck..." 302 ... "Nmap Scripting Engine"

    [RECON: Empty User-Agent Probe]
    10.0.0.11 - [07/Mar/2026] "GET /" 302 0 "-" "-"

    [ATTACK: Fuzz Faster U Fool]
    192.168.100.62 - [07/Mar/2026] "GET /admin/critical/zope" 200 ... "Fuzz Faster U Fool"
  • Exploit Frameworks: User-Agents containing "Metasploit", "Nikto", or "BeEF" indicate active vulnerability scanning or exploit attempts.
  • Mobile Hacking (Termux/NetHunter): Attacks from mobile devices often reveal themselves through "Python-requests", "libcurl", or specific Termux-related strings in the environment headers if not carefully spoofed.
  • SQL Injection: Look for "sqlmap" or long URLs containing single quotes ('), UNION, or SELECT.
  • Brute-Force Attacks: Attackers use automated tools to guess your password. Often, they idiotically forget to spoof their identity, revealing library agents like "python-requests" in the log.
    [ATTACK: Brute-Force Probing]
    192.168.100.16 - [08/Mar/2026] "PUT /admin/pass.php" 401 ... "python-requests/2.32.3"
  • Directory Traversal & Information Disclosure: Attackers use ../ to probe for system files or monitor APIs for internal path disclosures. Look for recursive traversal sequences or anomalous 200 OK responses on API probes.
    [ATTACK: Adventurous Traversal Probing]
    192.168.100.62 - [07/Mar/2026] "GET /admin/amusement/api.php?track=../../../../etc/passwd" 200 ... "curl/8.18.0"

    [VULNERABILITY: Internal Path Disclosure]
    {"status":"playing","track":"../custom_radio/OHNOOHYESfeat.mp3"}
  • Anomalous Agents: High-frequency requests using "curl" or "Python-requests" are often mindless malicious scripts. Genuine human traffic reveals a full browser agent.
    [ATTACK: Mindless Curl Traffic]
    192.168.100.62 - [07/Mar/2026] "PUT /admin/pass.php" 401 ... "curl/8.18.0"
  • Masquerading Bots: Be alert for generic strings like Mozilla/5.0 without version details, or unusually old browser versions used to bypass filters.
    [MASQUERADE: Fake Browser Agent]
    192.168.100.62 - [07/Mar/2026] "GET /admin/Login" 200 ... "Mozilla/5.0 (Windows NT 10.0; Win64; x64)"
  • Legitimate Traffic: Human browsers reveal full versioning details and standard HTTP referrers.
    [TRUSTED: Standard Browser]
    192.168.100.62 - [07/Mar/2026] "HEAD /admin/pass.php" 200 ... "Firefox/140.0"

Web Error Log

Displays PHP and Nginx system errors. If the dashboard or portal crashes, check here for the specific error message to troubleshoot.

iptables NAT

Shows the active Network Address Translation (NAT) rules in the Linux kernel. This confirms that traffic is being correctly redirected to the captive portal and masqueraded for internet access.
