System Troubleshooting

Consult this guide if you encounter operational issues with the SilvaSystems distribution.

Connectivity and Initialization

If client devices (Windows, iPhone, Android) report a successful connection but indicate "No Internet Access," or if the captive portal fails to load, it typically indicates a service initialization failure or kernel instability during boot.

Common Indicators:

  • Failure of specific systemd network services (e.g., [ERROR] Failed to start orange-wifi.service). These indicators are typically visible during the boot sequence when using an HDMI monitor to observe system logs.
  • Kernel Panic (System may become unresponsive or restart unexpectedly).
  • Use of counterfeit or low-performance SD/TF cards (causing I/O bottlenecks or filesystem synchronization errors).
  • External Access Point configuration error: Ensure your router is not overriding the gateway assignment. Client devices must receive 10.0.0.1 as the Default Gateway to reach the portal. If the router assigns its own internal IP address as the gateway, internet routing will fail.

Recommended Solution: Physical Power Cycle

Most initialization and kernel-level synchronization errors are resolved by a hardware reset.

  1. Disconnect the power source from the Orange Pi One.
  2. Wait 5 seconds to ensure complete power discharge.
  3. Reconnect the power source.
  4. Verify system status once the heartbeat LED indicates an active state.

Repeat this sequence if necessary until the system boots successfully and all services are active.
